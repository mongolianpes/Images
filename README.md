# Images
## Названачение
Микросервис для сохранения картинок в проекте [Farm](https://github.com/mongolianpes/Farm) <br>
Позволяет сохранять картинки, а также получать их извне пользователями сайта

Является форком проекта - https://habr.com/ru/articles/1004928/ Примечание: в данной реализации удалена функция для добавлена вотермарка.

## Функционал
- Сохранение изображений. Сохраняет изображения, сжимая картинки в случае необходимости и изменении их расширения
- Оттдает пользователям сайта сохраненные картинки по пути /images/путь/к/файлу из директории /files на порту 8080, в случае отсутствия картинки возвращает стандартную d.webp

## RPC запрос:
```
service ImageService {
    rpc DownloadImages(stream DownloadImagesRequest) returns (DownloadImagesResponse);
}
```
Подобнее в файле Images/proto/image.proto

## Важное
Для корректно работы необходимо что бы порт 8080 был открыт для доступа извне для получения клиентами сайта картинок
